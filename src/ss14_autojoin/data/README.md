# Bundled data

Everything here is generated by scripts in `tools/` from the standard library and released to the public
domain (CC0 1.0). Nothing is sampled or downloaded.

* `fanfare.wav`: the join sound, a brass "ta-da" (`tools/make_fanfare.py`).
* `icon.png` (256 px) and `icon.ico` (16 to 256 px): the app icon, a ring space station with a lit hub and
  solar panels (`tools/make_icon.py`). Used for the window's title bar and taskbar and for the executable.
