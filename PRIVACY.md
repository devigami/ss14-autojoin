# Privacy

SS14 Auto-Join collects no personal data: no accounts, no telemetry, no analytics, no crash reporting, no
update checks. The only network traffic is a status request to the game server you choose to watch. Login
stays inside the official Space Station 14 launcher. One local settings file is written and nothing else.

The full policy, including what the program reads and starts on your computer, is at
<https://devigami.github.io/ss14-autojoin/privacy/> (source: `docs/privacy.md`).
